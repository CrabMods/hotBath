# Hot Bath: Create bucket-filling check

The reported Spout bucket-filling problem is resolved in the maintained versions. Water, lava and all six built-in bath buckets appear in JEI's Filling by Spout category. Filling and Item Drain checks preserve the fluid type and amount and return the correct empty container. The guide shows the Create page when Create is installed and the unavailable page otherwise.

Verified combinations:

- Minecraft 1.20.1, Forge 47.4.16, Create 6.0.8, JEI 15.20.0.106, Patchouli 1.20.1-84.1-FORGE.
- Minecraft 1.21.1, NeoForge 21.1.215, Create 6.0.9, JEI 19.21.2.313, Patchouli 1.21.1-92-NEOFORGE.

The fixes were merged in PR #73 and #74. Issue #47 is closed. Tank interaction and moving-bath reports remain under investigation in #33. This does not establish compatibility with every modpack or moving-vehicle mod. The video uses original game frames held for comparison.
