# Hot Bath 4.1.1

Patch release for Minecraft 1.21.1 / NeoForge and Minecraft 1.20.1 / Forge.

## Fixed

- Restored ordinary water and lava bucket filling when Hot Bath is installed, including Create Spouts.
- Restored fluid capabilities for built-in bath buckets and dynamic datapack bath buckets.
- Fixed Create Spout filling of stacked empty buckets while preserving the bath fluid identity.
- Kept legacy bucket metadata unchanged during reads and simulated transactions; invalid bath fluid IDs do not consume buckets or fluid.

## Validation and remaining scope

Both branches passed JVM regression tests, 30 native Create filling transactions and 20 real Spout/emptying transactions in a hidden client across 10 fluids. Tested with Create 6.0.9 on NeoForge 1.21.1 and Create 6.0.8 on Forge 1.20.1. Test and recording harnesses are excluded from the production JARs.

Recipe-viewer GUI behavior and other Create compatibility work remain under review in [#47](https://github.com/CrabMods/hotBath/issues/47) and [#33](https://github.com/CrabMods/hotBath/issues/33). This release does not claim full modpack acceptance.
